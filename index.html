O fio condutor

Toda IA aprende padrões para prever a próxima coisa

A próxima palavra. O próximo pixel. A próxima jogada. Essa ideia simples explica ao mesmo tempo as forças e os limites da IA — e liga tudo o que vimos.

📚 Muitos exemplos→🧮 Ajuste de padrões (treino)→🔮 Previsão sobre algo novo
A palestra em 4 perguntas

Cada bloco responde uma e puxa a próxima

1

Como a IA prevê

Um modelo de linguagem calcula a probabilidade da próxima palavra. A temperatura decide o quanto ele arrisca; o contexto muda tudo.

Votação ao vivo
2

Como a IA aprende

Os padrões vêm dos dados. Dados pouco variados ensinam a coisa errada — isso é viés. Modelo bom vem de dados bons.

Teachable Machine
3

Como enganar a IA

Se ela só segue padrões, um texto bem escrito pode passar por cima das regras. Isso é prompt injection, o risco nº 1 do OWASP.

Desafio Gandalf
4

Quando a IA erra

Ela prevê o texto mais plausível, não o mais verdadeiro. Por isso inventa com confiança: alucinação. A IA rascunha, você verifica.

Verdade ou inventado?

Na prática

IA no dia a dia de quem desenvolve

Faça Evite
Use IA para explicar código, gerar testes, revisar e acelerar tarefas repetitivas Aceitar código que você não entende — no trabalho, o bug é seu
Dê contexto: linguagem, versão, objetivo, restrições, exemplos Pedidos vagos (“faz um sistema”)
Peça alternativas e compare Tratar a primeira resposta como a certa
Rode, teste e leia a documentação oficial Confiar em nomes de funções e pacotes sem conferir
Remova dados pessoais e sigilosos antes de colar algo numa ferramenta pública (lembre da LGPD) Colar dados de clientes, senhas, chaves de API ou código confidencial

Três coisas para levar

  1. IA é copiloto, não piloto: entenda cada linha que você aceitar.
  2. Aprenda o que está por baixo: dados, probabilidade, APIs.
  3. Segurança desde o primeiro prompt.

Glossário

Termos essenciais
Machine learning
Subárea da IA em que o sistema aprende padrões a partir de exemplos, em vez de seguir regras escritas à mão.
LLM
Large Language Model: modelo de linguagem treinado em grandes volumes de texto para prever o próximo token.
Token
Pedaço de texto (palavra, parte de palavra ou símbolo) que o modelo processa.
Temperatura
Parâmetro que controla o quanto o sorteio do próximo token é previsível ou arriscado.
Transformer / atenção
Arquitetura dos LLMs atuais; a atenção pondera quais partes do contexto importam para cada previsão.
Viés
Distorção sistemática no comportamento do modelo, geralmente herdada dos dados.
Prompt injection
Ataque que insere instruções no texto lido pelo modelo para contornar as regras do sistema.
Alucinação
Informação falsa ou inventada apresentada pelo modelo como verdadeira.
Mais termos
Inteligência Artificial
Área que cria sistemas capazes de realizar tarefas que associamos à inteligência humana.
Deep learning
Machine learning com redes neurais de muitas camadas.
Rede neural
Modelo formado por camadas de unidades matemáticas conectadas por pesos ajustáveis.
Pesos / parâmetros
Os números internos que o treino ajusta. LLMs grandes têm bilhões deles.
Treino × inferência
Treino é ajustar o modelo com exemplos; inferência é usá-lo para prever dados novos.
Transferência de aprendizado
Reaproveitar um modelo já treinado e ajustar só a parte final para uma tarefa nova.
Overfitting
Quando o modelo “decora” os exemplos de treino e vai mal em dados novos.
Janela de contexto
Quantidade máxima de tokens que o modelo consegue considerar de uma vez.
Prompt de sistema
Instruções do desenvolvedor que definem o comportamento do assistente.
Jailbreak
Tentativa de fazer o modelo ignorar suas regras de segurança de modo geral.
RAG
Técnica que busca documentos relevantes e os entrega ao modelo antes de ele responder.
Fine-tuning
Treino adicional de um modelo já pronto para especializá-lo numa tarefa.
Agente
Sistema em que o LLM decide e executa ações usando ferramentas.
