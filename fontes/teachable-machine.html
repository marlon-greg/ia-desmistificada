Neste guia, todo botão aparece assim: Train Model (treinar modelo) — o nome exato que você vai ver na tela, seguido da tradução. As ilustrações são esquemas simplificados da tela, não capturas reais: o visual do site pode mudar um pouco com o tempo.

Passo 1

O que é e do que você precisa

O Teachable Machine é uma ferramenta gratuita do Google para treinar modelos de machine learning direto no navegador. Você mostra exemplos, clica em treinar e, em segundos, tem um modelo que reconhece imagens, sons ou poses do corpo.

Por trás, ele usa transferência de aprendizado: parte de um modelo que já foi treinado com muitas imagens e já reconhece formas, bordas e texturas. Você só ensina a parte final — por isso poucos exemplos bastam.

✅ Você precisa de

  • Um computador com webcam (o celular até abre o site, mas a experiência é bem melhor no computador)
  • Navegador atualizado (Chrome, Edge ou Firefox)
  • 15 minutos

🔒 Seus dados

O treino acontece no seu navegador: as imagens da webcam não são enviadas para treinar nada fora do seu computador. Elas só saem daí se você salvar o projeto no Google Drive ou publicar o modelo.

🎯 O que vamos construir

Um modelo que reconhece três situações pela webcam: Joinha 👍, Mão aberta ✋ e Nada (só você, sem gesto). É o mesmo que fizemos ao vivo na palestra.

Passo 2

Criar o projeto

  1. Acesse teachablemachine.withgoogle.com.
  2. Clique em Get Started (começar).
  3. Na tela New Project (novo projeto), escolha Image Project (projeto de imagem).
  4. Escolha Standard image model (modelo de imagem padrão). A outra opção, Embedded image model, é para microcontroladores — não precisamos dela.
Esquema · tela “New Project”
1Clique em Image Project e depois em Standard image model.
Passo 3

Criar as classes

Uma classe é cada categoria que o modelo vai aprender a diferenciar.

A tela de trabalho tem três colunas, da esquerda para a direita: classes (seus exemplos) → treino → teste.

Esquema · tela de trabalho do projeto de imagem
1Clique no lápis ✎ ao lado de “Class 1” para renomear a classe. 2Add a class (adicionar uma classe) cria mais uma categoria. 3Webcam grava exemplos pela câmera; Upload (enviar) usa imagens do computador. 4Train Model (treinar modelo) e o menu Advanced (avançado). 5Preview (prévia): as barras de Output (saída) mostram a confiança em cada classe.
  1. Renomeie Class 1 para Joinha e Class 2 para Mão aberta.
  2. Clique em Add a class e crie a classe Nada.

💡 Por que a classe “Nada”?

O modelo sempre escolhe uma das classes que conhece. Sem a classe “Nada”, quando você estiver parado ele vai dizer, com confiança, que é “Joinha” ou “Mão aberta”. A classe de fundo ensina a ele o que é “nenhum gesto”.

Passo 4

Coletar exemplos

Esta é a etapa que mais importa. A qualidade do modelo depende quase toda daqui.

  1. Na classe Joinha, clique em Webcam. Se o navegador pedir permissão para usar a câmera, permita.
  2. Faça o gesto e segure o botão Hold to Record (segure para gravar). Enquanto você segura, ele tira várias fotos por segundo.
  3. Junte de 50 a 100 imagens. Enquanto grava, varie: aproxime e afaste a mão, mude o ângulo, use a mão esquerda e a direita.
  4. Repita para Mão aberta e para Nada (você parado, mãos abaixadas, olhando para a câmera).

✅ Bons exemplos

  • Quantidade parecida em todas as classes
  • Variedade de ângulo, distância e posição
  • Se possível, mais de uma pessoa e mais de um fundo
  • Luz parecida com a de onde você vai usar o modelo

⚠️ Armadilhas

  • Uma classe com 200 fotos e outra com 20
  • Todas as fotos idênticas (mão parada no mesmo lugar)
  • Mudar de roupa ou de lugar só numa das classes — o modelo aprende a roupa, não o gesto

Prefere usar fotos prontas? Clique em Upload e arraste imagens do computador, ou escolha uma pasta do Google Drive. Funciona para qualquer coisa: tipos de folha, raças de cachorro, peças com defeito e sem defeito.

Errou uma foto? Passe o mouse sobre a miniatura e clique na lixeira para apagar.

Passo 5

Treinar

  1. Clique em Train Model (treinar modelo).
  2. Aparece uma mensagem de preparação dos dados e depois o progresso do treino.
  3. Não troque de aba e não minimize o navegador até terminar. Muitos navegadores economizam processamento em abas que não estão visíveis, e o treino pode travar ou ficar muito lento.

🧠 O que está acontecendo agora

O modelo olha cada exemplo, faz uma previsão, compara com a resposta certa (a classe onde você colocou a foto) e ajusta seus pesos um pouquinho para errar menos. Ele repete esse ciclo várias vezes sobre todas as imagens. Como só a parte final do modelo está sendo ajustada (transferência de aprendizado), isso leva segundos.

Passo 6

Testar

  1. Quando o treino termina, a área Preview (prévia) liga a webcam sozinha.
  2. Faça cada gesto e observe as barras de Output (saída): cada uma mostra a confiança do modelo em uma classe, de 0% a 100%.
  3. Teste casos difíceis: gesto pela metade, mão muito perto, mão muito longe, outra pessoa, outra iluminação.
  4. Para testar com uma imagem do computador, troque a entrada de Webcam para File (arquivo) no seletor acima da imagem. O botão Input (entrada) liga e desliga a câmera.

💡 Confiança não é certeza

Uma barra em 98% quer dizer que, para o modelo, aquela classe é muito mais parecida com o que ele está vendo do que as outras. Não quer dizer que ele esteja certo. Se ele está confiante e errado, o problema quase sempre está nos dados de treino.

✏️ Desafio rápido

Descubra pelo menos duas situações em que o seu modelo erra com confiança alta. Para cada uma, pense: que exemplos estavam faltando no treino? Adicione esses exemplos, treine de novo e veja se melhorou.

Passo 7

Ajustes avançados

Clique em Advanced (avançado), abaixo do botão de treino. Os valores padrão funcionam bem; mexa só para experimentar.

OpçãoPadrãoO que significaSe aumentar…
Epochs (épocas)50Quantas vezes o modelo passa por todas as imagens de treino.Aprende mais os exemplos — mas, demais, pode “decorar” (overfitting).
Batch Size (tamanho do lote)16Quantas imagens ele olha antes de cada ajuste dos pesos.Ajustes mais estáveis e em menor número por época.
Learning Rate (taxa de aprendizado)0.001O tamanho de cada ajuste nos pesos.Aprende mais rápido, mas pode “passar do ponto” e ficar instável.

Em Under the hood (por baixo do capô) aparecem gráficos de acurácia e perda (loss) por época, e a acurácia por classe. Repare que o site separa automaticamente uma parte das suas imagens para teste — exatamente a ideia de conjunto de treino e conjunto de teste. Reset Defaults (restaurar padrões) volta aos valores originais.

🧪 Experimente

Treine com 5 epochs e depois com 200. Compare como o modelo se comporta com gestos que não estavam no treino. Mais treino é sempre melhor?

Passo 8

Experimento de viés

O mesmo experimento da palestra. Ele mostra, em miniatura, um dos maiores problemas da IA no mundo real.

  1. Crie um projeto novo. Treine Joinha e Mão aberta com exemplos de uma só pessoa, num fundo só.
  2. Agora, para deixar o efeito bem visível: grave a classe Joinha usando uma camiseta clara e a classe Mão aberta usando um casaco escuro.
  3. Treine e teste trocando de roupa: faça joinha usando o casaco escuro. O que o modelo diz?
  4. Peça para outra pessoa testar, em outro lugar. Anote quando ele erra.
  5. Adicione nas mesmas classes exemplos com as duas roupas, de outra pessoa e de outro fundo. Treine de novo e compare.

📌 O que você acabou de ver

O modelo não sabe o que você “quis” ensinar. Ele aprende qualquer diferença que separe as classes nos dados — e a roupa era a diferença mais fácil. Em sistemas reais (crédito, contratação, reconhecimento facial), dados pouco variados geram o mesmo tipo de erro, só que com pessoas de verdade sendo prejudicadas. Modelo bom vem de dados bons.

Passo 9

Salvar e exportar

Salvar o projeto (para continuar depois)

Clique no menu ☰ no canto superior esquerdo:

  • Save project to Drive (salvar projeto no Drive) — guarda tudo, inclusive as imagens, no seu Google Drive.
  • Download project as file (baixar projeto como arquivo) — um arquivo que você abre depois com Open project from file.

Exportar o modelo (para usar em outro lugar)

  1. Na área Preview, clique em Export Model (exportar modelo).
  2. Na aba Tensorflow.js, escolha Upload (shareable link) (enviar, com link compartilhável) e clique em Upload my model (enviar meu modelo). O site gera um link público para o modelo. Só o modelo treinado é enviado, não as suas fotos.
  3. Logo abaixo aparece um código de exemplo pronto para copiar. As outras abas oferecem o modelo para Tensorflow (Python) e Tensorflow Lite (celulares e dispositivos pequenos).

Desafio extra: o seu modelo num site

Com o link do modelo, esta página mínima liga a webcam e mostra a classe mais provável. Salve como index.html, troque o endereço do modelo e abra num servidor local (por exemplo, a extensão Live Server do VS Code).

<div id="saida">Carregando…</div>
<script src="https://cdn.jsdelivr.net/npm/@tensorflow/tfjs@latest/dist/tf.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/@teachablemachine/image@latest/dist/teachablemachine-image.min.js"></script>
<script>
  const URL = "https://teachablemachine.withgoogle.com/models/SEU_MODELO/"; // troque aqui
  let model, webcam;

  async function init() {
    model = await tmImage.load(URL + "model.json", URL + "metadata.json");
    webcam = new tmImage.Webcam(300, 300, true); // largura, altura, espelhar
    await webcam.setup();                        // pede permissão da câmera
    await webcam.play();
    document.body.appendChild(webcam.canvas);
    requestAnimationFrame(loop);
  }

  async function loop() {
    webcam.update();
    const prev = await model.predict(webcam.canvas); // [{ className, probability }, ...]
    const top = prev.reduce((a, b) => (b.probability > a.probability ? b : a));
    document.getElementById("saida").textContent =
      top.className + " · " + Math.round(top.probability * 100) + "%";
    requestAnimationFrame(loop);
  }

  init();
</script>

O código de exemplo oficial, gerado na própria janela de exportação, também tem uma versão para p5.js. Use-o como referência caso as bibliotecas mudem de versão.

Passo 10

Áudio e pose

O fluxo é o mesmo — classes, exemplos, treino, teste — muda só o tipo de dado.

🎙️ Audio Project (projeto de áudio)

  • Já começa com a classe Background Noise (ruído de fundo): grave o silêncio do ambiente. Ela exige mais amostras que as outras.
  • Cada amostra é um trecho curto de som, gravado pelo microfone.
  • Ideias: reconhecer palmas, assobio, “sim” e “não”, o som de um eletrodoméstico.

🧍 Pose Project (projeto de pose)

  • Em vez da imagem inteira, o modelo usa a posição de pontos do corpo (ombros, cotovelos, joelhos…), detectados pela webcam.
  • Como olha o “esqueleto”, sofre menos com roupa e fundo.
  • Ideias: reconhecer postura correta ao sentar, poses de yoga, movimentos de exercício.

🔎 Para pensar

Por que um modelo de pose tende a sofrer menos com o viés da roupa do que um modelo de imagem? Que tipo de viés ele ainda pode ter? (Dica: pense em quem gravou os exemplos — altura, tipo de corpo, mobilidade.)

🚀 Leve para o portfólio

Publique a página do seu modelo no GitHub Pages e escreva um README com: o problema, as classes, quantas imagens usou, onde o modelo erra e por quê. Mostrar que você entende os limites do modelo vale mais do que dizer que ele acerta 99%.
